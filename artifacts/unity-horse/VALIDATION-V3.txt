REMAINING VISUAL LIMITS
The horse base mesh is unchanged and is not a scan of a real animal.
The mounted jockey uses a scanned head with the existing racewear body.
The audience repeats three static seated characters; it is not 4,885 unique
animated people. The stadium is original procedural geometry, not a replica
of a surveyed real venue. GTA-level photorealism has not been achieved.
The user has a licensed horse asset; its exact link or local file path is
still needed before replacing and verifying the animal model.
