APEX Superbike Racing — asset credits

Motorcycles, helmets, track, physics and interface: authored for this project.
These are original generic motorcycles inspired by the supplied reference, not
official BMW, Ducati or Triumph vehicle models. Three liveries share a base mesh
with distinct power, acceleration and handling configurations.

Rider geometry: CC0 Vitruvian / CharMorph character from Agile Lens VitruvianGodot.
https://github.com/ibrews/VitruvianGodot
https://github.com/ibrews/VitruvianGodot/blob/main/NOTICE.md
Vitruvian: Sean Buckley and Olaf Delgado-Friedrichs. CharMorph and rig: Upliner.
This project derives its own motorcycle pose, fitted black/red clothes, gloves
and boots from the workspace's CC0 rider. No Mixamo animations are included.
Reproduction script: tools/bike-assets/prepare-rider.py.

Environment: Poly Haven CC0
https://polyhaven.com/license
Grass maps: https://polyhaven.com/a/grass_ground
Terrain photograph: https://polyhaven.com/a/aerial_rocks_02
Tree cards: local transparent Blender renders of Island Tree 01:
https://polyhaven.com/a/island_tree_01
Environment lighting: https://polyhaven.com/a/kloofendal_48d_partly_cloudy
Tree cards are crossed planes using rendered tree photographs, not volumetric
tree meshes. All assets are bundled locally.

Grandstand audience: existing project-generated artwork, originally generated
using image_gen for horse racing. Source provenance is retained in this pack as
environment/crowd-provenance.json. This is artwork, not a photograph of real fans.
