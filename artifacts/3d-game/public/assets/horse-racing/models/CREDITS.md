# Racing model credits

`thoroughbred.glb` is a smoothed derivative of the animated Horse by Mirada, originally made for ROME / 3 Dreams of Black and distributed in the Three.js examples (r185). Original: https://github.com/mrdoob/three.js/blob/r185/examples/models/gltf/Horse.glb

Artist: https://mirada.com/ — project: https://rome.mrdoob.com/ — original project and its asset terms: https://github.com/dataarts/3-dreams-of-black

The included Three.js repository license is retained as THREE-LICENSE.txt. The local preparation script `tmp/build-racehorse-3d.mjs` applies two Loop subdivision passes to the mesh and all gallop morph targets, preserves the original animation, and recalculates normals. Riders, racing silks, tack, numbers, stadium and scenery are created in the game code. The game applies individual coat materials at runtime.
