BUILD FROM WORKSPACE ROOT, AFTER HUB LICENSE ACTIVATION
  npm run sports:unity:prepare
  npm run sports:unity:build
  npm run sports:build

To prepare the main website bundle as well:
  npm run sports:unity:website
  node tools/sports-assets/prepare-unity-overlay.mjs
The overlay is a web-image build context. Updating the local Docker website
requires building that image and recreating only the web service.

Or add this directory to Unity Hub, open it, and use:
  Arena Sports > Prepare project
  Arena Sports > Build website WebGL

The preparation command creates the Arena scene, URP assets, external player
materials, generic animation imports, post processing and project settings.
The build command stages WebGL under Builds/WebGL and copies a successful build
to ../3d-game/public/unity-sports. ready.json is written only after success.
The website chooses Unity only when a valid ready.json is present. Until then,
the existing Three.js renderer remains active.

ASSETS AND REPRODUCTION
tools/sports-assets/upgrade-unity-human.py is the current Blender pipeline.
It combines the CC0 Vitruvian face/eyes/skin with the weighted sports body,
repairs the shirt, bakes atlases and exports three LODs with three materials.
Run validate-human-fbx.py in Blender before building: all six exported meshes
must use the correct atlas in UV0. Copy UV values before deleting old layers;
Blender UV layer references can change when earlier layers are removed.
export-unity.py remains the earlier source export. Six clips are retained.
