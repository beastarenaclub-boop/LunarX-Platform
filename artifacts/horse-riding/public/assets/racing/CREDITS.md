# Turf Club asset credits

`horse.glb`: animated horse by **Mirada**, originally created for **ROME / 3 Dreams of Black**. Distributed in the Three.js examples. Source pinned to Three.js r185:

https://github.com/mrdoob/three.js/blob/r185/examples/models/gltf/Horse.glb

Original example and attribution:
https://github.com/mrdoob/three.js/blob/r185/examples/webgl_morphtargets_horse.html
https://mirada.com/
https://rome.mrdoob.com/

Three.js repository license is included in `THREE-LICENSE.txt`; retain the original artist credit with the model. The original ROME project is available at https://github.com/dataarts/3-dreams-of-black (see its asset licensing terms).

The `higgsfield/` directory contains original AI-generated photographic media created for this project through **Higgsfield** (https://higgsfield.ai/) on 2026-10-01. Venue photos and runner portraits use GPT Image 2.5; six 18-second venue films and their soundtracks use Seedance 2.5. Locally encoded H.264/AAC versions are included at 1080p and 720p. `GENERATIONS.json` records the source generation IDs and model names. These are fictional cinematic illustrations; they do not depict the simulator's random finish order.

In the optional 3D simulation, all racecourse geometry, jockeys, saddle cloths, audience instances, scenery, surface textures, signs and synthesized audio are generated locally by this project's source. Coat materials and jockeys are applied by the application; the supplied horse animation is preserved. All runtime assets are local: no CDN, remote fonts, remote audio or paid asset keys are required to play.

Venue and race names are fictional.
