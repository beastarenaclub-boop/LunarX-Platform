ROYAL PARK - UNITY PLAYER, VISUAL REVISION 4

Install Node.js if needed, then run START.cmd.
Open http://localhost:5294/ in Chrome or Edge and keep the console open.
Camera, lighting, restart, pause and fullscreen controls are available.

This portable player is a graphics exhibition. It has no account or wallet.
The full betting game is in the original workspace:
http://127.0.0.1:5293/horse-racing (run START-HORSE-RACING.cmd)
It uses the existing API server, authentication and server race plan.

Revision 4 replaces the old horse with the CC0 Grab3D Bay Horse, reduced to
approximately 32,000 triangles, with PBR textures and a fitted 56-bone rig.
Idle/Gallop motion is based on afk-rig / Mesh2Motion CC0 animations. The jockey
and saddle follow the horse's spine. Rebuilt tree canopies use complete leaf
cards, restored opacity and coverage-preserving mipmaps. The scanned audience and performance work
from revision 3 remain included. This is not GTA-level photorealism.

This package contains the compiled game. The source Unity project remains in
artifacts/unity-horse in the original workspace. See ASSET-LICENSES.md for the
model sources and terms. Do not redistribute standalone Renderpeople scans.
